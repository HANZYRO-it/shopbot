# Бесплатный запуск бота 24/7 без банковской карты

Схема из трёх бесплатных сервисов:

| Что | Где | Зачем |
|---|---|---|
| База данных (товары, заказы) | **Neon** (PostgreSQL) | хранит данные, не стирается при перезапусках |
| Программа бота | **Render** (Web Service, Free) | принимает сообщения от Telegram и отвечает |
| «Будильник» | **cron-job.org** | раз в 5 минут заходит на сайт бота, чтобы Render не усыплял его |

Ваш компьютер для работы бота **не нужен**.

> Бот работает в режиме **webhook**: Telegram сам присылает сообщения на адрес сервиса.
> Шаги диалога (оформление заказа, добавление товара) хранятся в базе, поэтому не теряются при перезапуске.

---

## Что важно знать заранее (честно)

- Бесплатный тариф Render **усыпляет** сервис через 15 минут без запросов, пробуждение занимает около минуты.
  Именно поэтому нужен «будильник» (шаг 5). Если будильник сломается, первое сообщение клиента будет обработано
  с задержкой до минуты (Telegram повторит доставку сам), потом всё снова быстро.
- Free-тариф Render официально не предназначен для серьёзного продакшена, условия бесплатных планов могут меняться.
  Для небольшого магазина это нормальный старт; если магазин вырастет, перейдите на VPS за 3-5 € (код менять не нужно).
- В месяце 744 часа (31 день), бесплатный лимит Render — 750 часов, то есть одного постоянно работающего
  сервиса хватает впритык. Не создавайте на этом аккаунте других бесплатных сервисов.
- Neon бесплатно даёт 0,5 ГБ данных. Для магазина на сотни товаров и тысячи заказов этого достаточно
  (фото хранятся на серверах Telegram, а не в базе).

## Шаг 0. Замените токен бота (рекомендую)

Токен, который вы показывали в чате, лучше считать скомпрометированным.

1. Откройте **@BotFather** → `/revoke` → выберите своего бота → получите новый токен.
2. Используйте только новый токен во всех шагах ниже.

---

## Шаг 1. База данных на Neon

1. Откройте https://neon.com и нажмите **Sign up** (войдите через Google/GitHub или почтой). Карта не требуется.
2. Создайте проект: название любое (например `shop`), регион — **Europe (Frankfurt)**, если он есть в списке.
3. На странице проекта нажмите **Connect** и скопируйте строку подключения, которая начинается с `postgresql://`.
   Убедитесь, что пароль виден (а не точки): включите «Show password» или скопируйте через кнопку Copy.
4. Сохраните её в блокноте: это ваш `DATABASE_URL`. Она выглядит примерно так:
   `postgresql://neondb_owner:ПАРОЛЬ@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

Эту строку **никому не показывайте**: с ней можно читать и менять базу.

## Шаг 2. Проверка на своём компьютере (очень рекомендую)

Это самый быстрый способ найти ошибки, пока вы ещё не выложили бота в интернет.

1. Распакуйте новый архив поверх старой папки (файл `.env` и папка `venv` останутся, их в архиве нет).
   В cmd (архив лежит в «Загрузках»):

   ```cmd
   cd %USERPROFILE%\Downloads
   tar -xf telegram-shop-bot-free.zip -C %USERPROFILE%\Desktop
   cd %USERPROFILE%\Desktop\telegram-shop-bot
   venv\Scripts\activate
   pip install -r requirements.txt
   notepad .env
   ```

2. В `.env` впишите новый токен и добавьте строку (без кавычек и пробелов):

   ```
   BOT_TOKEN=новый_токен
   ADMIN_IDS=ваш_id
   DATABASE_URL=postgresql://...вся_строка_из_Neon...
   ```

3. Запустите:

   ```cmd
   python -m shopbot
   ```

   В логе должны появиться строки `Бот запущен: @...` и `Режим polling`.
4. В Telegram: `/start`, затем `/admin` → создайте категорию и товар, оформите тестовый заказ с другого аккаунта
   (или с этого же) и проверьте, что вам пришло уведомление.
5. Остановите бота: `Ctrl+C`.

Если на этом шаге появилась ошибка, пришлите её текст мне, исправим до выкладки.

> После выкладки на Render **больше не запускайте бота локально**: локальный запуск снимает вебхук,
> и бот на Render перестанет получать сообщения до его перезапуска.

## Шаг 3. Загрузка кода на GitHub (нужен Render)

Render берёт код из GitHub. Аккаунт бесплатный, карта не нужна.

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+ → New repository**. Имя, например, `shop-bot`. Выберите **Private**. Нажмите **Create repository**.
3. Подготовьте чистую папку (без `.env` и `venv`):

   ```cmd
   mkdir %USERPROFILE%\Desktop\shop-deploy
   cd %USERPROFILE%\Downloads
   tar -xf telegram-shop-bot-free.zip -C %USERPROFILE%\Desktop\shop-deploy
   explorer %USERPROFILE%\Desktop\shop-deploy\telegram-shop-bot
   ```

4. На странице нового репозитория нажмите **uploading an existing file**.
5. В открывшейся папке нажмите `Ctrl+A` и перетащите **всё** в окно браузера (включая папки `shopbot` и `deploy`
   и файлы с точкой: `.gitignore`, `.dockerignore`, `.env.example`).
6. Внизу нажмите **Commit changes**.
7. Проверьте, что в репозитории **нет** файла `.env` (должен быть только `.env.example`).

## Шаг 4. Бот на Render

1. Откройте https://render.com → **Get Started** → войдите через GitHub.
2. **New + → Web Service** → выберите ваш репозиторий `shop-bot` (при необходимости разрешите Render доступ к нему).
3. Настройки:
   - **Name:** любое, например `my-shop-bot`
   - **Region:** Frankfurt (EU Central), ближе к Neon
   - **Branch:** `main`
   - **Language / Runtime:** **Docker**
   - **Instance Type:** **Free**
4. В разделе **Environment Variables** добавьте (по одной):

   | Key | Value |
   |---|---|
   | `BOT_TOKEN` | новый токен |
   | `ADMIN_IDS` | ваш ID |
   | `DATABASE_URL` | строка из Neon |
   | `SHOP_NAME` | название магазина |
   | `CURRENCY` | `€` |
   | `CONTACTS` | `Telegram: @ваш_ник` |
   | `PAYMENT_INFO` | текст про оплату и доставку |
   | `TIMEZONE` | `Europe/Berlin` |

   Переменную `WEBHOOK_URL` **не добавляйте**: Render задаёт адрес сам.
5. Нажмите **Create Web Service**. Сборка займёт несколько минут.
6. Откройте вкладку **Logs**. Успех выглядит так: `Бот запущен: @...` и `Режим webhook: порт ...`.
7. Скопируйте адрес сервиса (вверху страницы, вида `https://my-shop-bot.onrender.com`) и откройте его в браузере:
   должно быть написано `ok`.
8. Напишите боту `/start` в Telegram, он должен ответить.

Если Render запросит банковскую карту, остановитесь и напишите мне, какой именно шаг и что за сообщение:
по найденным мной данным для Free-сервисов карта не нужна, но условия у провайдеров могут меняться.

## Шаг 5. «Будильник» на cron-job.org

1. Зарегистрируйтесь на https://cron-job.org (бесплатно).
2. **Create cronjob**:
   - **Title:** `shop-bot ping`
   - **URL:** адрес вашего сервиса на Render, например `https://my-shop-bot.onrender.com/`
   - **Execution schedule:** every 5 minutes (каждые 5 минут)
3. Сохраните. Через несколько минут в истории выполнений должен быть статус **200 OK**.

Теперь сервис не засыпает. Страница `/` не обращается к базе, поэтому «пинги» не мешают бесплатной базе Neon отдыхать.

---

## Шаг 6. Финальная проверка

1. Выключите свой компьютер (или просто закройте все окна cmd).
2. С телефона: `/start` у бота, откройте каталог, добавьте товар в корзину, оформите заказ.
3. Вам в личку должно прийти уведомление «🔔 Новый заказ!» с кнопками смены статуса.
4. Проверьте состояние вебхука (вставьте свой токен вместо `ТОКЕН`):
   `https://api.telegram.org/botТОКЕН/getWebhookInfo`
   В ответе должны быть ваш адрес Render, `pending_update_count` около 0 и **нет** `last_error_message`.

## Обновление бота

Изменили файлы в репозитории GitHub → Render сам пересоберёт и перезапустит сервис.
Данные не теряются: они в Neon.

## Резервные копии

Раз в сутки бот присылает админам в Telegram файл `shop-….json` с полной копией данных.
Сохраняйте их. Восстановление описано в README (`python -m shopbot.restore файл.json`).

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| В логах Render `Не удалось подключиться к базе` | Проверьте `DATABASE_URL`: целиком, с паролем, без кавычек и пробелов |
| `ok` в браузере есть, а бот молчит | Откройте `getWebhookInfo` (шаг 6.4): смотрите `last_error_message`. Проверьте, что локально бот не запущен |
| Бот отвечает с задержкой около минуты | Сервис успел уснуть: проверьте историю в cron-job.org (должны быть успешные запросы каждые 5 минут) |
| Нет уведомлений о заказах | Админ должен один раз нажать `/start` у бота; проверьте `ADMIN_IDS` |
| Render пишет, что часы бесплатного плана закончились | В этом аккаунте работает больше одного бесплатного сервиса. Оставьте один |
| После локального запуска бот на Render замолчал | Render → Manual Deploy → Restart (вебхук поставится заново) |
| Ошибка при сборке на Render | Скопируйте последние 30 строк лога из вкладки Logs и пришлите мне |
